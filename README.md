# Hotel Booking Cancellation Analysis

## Objective
This project aims to analyze factors influencing hotel booking cancellations and build a model to identify high-risk customers.

## Dataset
The dataset includes booking information such as customer type, lead time, previous cancellations, and reservation details.

## Process
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Logistic regression modeling
- Feature importance analysis

## Key Findings
- Previous cancellations and repeat customer status are the most influential factors
- High-risk customers (~6.7%) show an 85.1% cancellation rate
- Lead time and waiting status significantly impact cancellation probability

## Business Insights
- Apply prepayment and confirmation strategies to high-risk customers
- Use upselling strategies for low-risk customers
- Design balanced service packages to improve retention

## Tools
Python, pandas, scikit-learn, statsmodels, matplotlib
